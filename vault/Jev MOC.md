# Jev / TypeSafe — Index

> [!abstract] What Is Jev?
> **Jev** is TypeSafe's **System One** model. Sends natural language + app state → returns typed decisions (choice/score/probability), not generated text. ~100 ms. Code owns the workflow; Jev fills semantic judgment slots.
